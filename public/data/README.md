# Site data

Content the site reads at runtime.

| Path | What | License |
|---|---|---|
| `questions/*.json` | Questions (code, options, feedback, explanations) | CC BY-SA 4.0, see `LICENSES/CC-BY-SA-4.0.txt` |
| `courses/*.json` | Course structure (lessons and question order) | CC BY-SA 4.0 |
| `catalog.json` | The public course catalog (courses, free question counts, start question, premium "coming soon" counts) | CC BY-SA 4.0 |
| `concepts.json` | Copy of the shared concept map vocabulary | MIT, see `LICENSES/MIT.txt` |
| `index.json`, `index-<course>.json` | Derived index of each course's questions (`index.json` is the Python course) | CC BY-SA 4.0 |
| `concepts-<course>.json` | Copy of a course vocabulary (`concepts.json` is Python) | MIT |
