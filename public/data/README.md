# Site data

Content the site reads at runtime.

There are currently 44 free sample questions (34 Python, 5 Production, 5 SQL). Other course content is not included in this repository.

| Path | What | License |
|---|---|---|
| `questions/*.json` | Free questions (code, options, feedback, explanations) | CC BY-SA 4.0, see `LICENSES/CC-BY-SA-4.0.txt` |
| `courses/*.json` | Course structure (lessons and question order) | CC BY-SA 4.0 |
| `catalog.json` | Public catalog, free question counts, start questions and premium counts/status | CC BY-SA 4.0 |
| `index.json`, `index-production.json`, `index-sql.json` | Derived indexes for Python, Production and SQL questions | CC BY-SA 4.0 |
| `concepts.json` | Python vocabulary | MIT, see `LICENSES/MIT.txt` |
| `concepts-production.json`, `concepts-sql.json` | Production and SQL vocabularies | MIT, see `LICENSES/MIT.txt` |
| `traces/*.json` | Question step-playback data | CC BY-SA 4.0 |
